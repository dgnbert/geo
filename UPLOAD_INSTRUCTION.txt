BUCEPHALUS — ГОТОВАЯ ВЕРСИЯ ДЛЯ GITHUB PAGES

1. Откройте репозиторий geo.
2. Удалите из него прежние файлы, которые были загружены ранее.
3. Загрузите в корень репозитория ВСЕ файлы и папки из этого архива.
4. Файл index.html должен находиться сразу в корне репозитория, а не внутри дополнительной папки.
5. В GitHub откройте Settings -> Pages.
6. Выберите Deploy from a branch, ветку main и папку / (root).
7. Сохраните настройки и подождите 1–5 минут.

Готовый адрес:
https://dgnbert.github.io/geo/

Пути к стилям, скриптам и изображениям уже настроены для раздела /geo/.
